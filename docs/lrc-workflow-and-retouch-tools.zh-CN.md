# 从 Lightroom Classic + Photoshop 迁移到 LightCraft + PhotoCraft：现状、做法和后续计划

- 依据：LightCraft 官方 `v0.20.0`（与 main `c2e9c45` 在相关代码上相同）、PhotoCraft main `6b6d9db`，阅读源码；每条结论都经过独立核查。原始数据见 `docs/research-data/lrc-workflow.json` 和 `retouch-tools.json`。
- Lightroom Classic 简称 LrC，Photoshop 简称 PS。文中的“改键”都在 LightCraft 的 **帮助 ▸ 键盘快捷键**（⌘/ 或 Ctrl+/）里完成。

## 一、为什么 LightCraft 用起来“不像 LrC”

LightCraft 照搬的是**云端版 Lightroom（Lightroom desktop）的单窗口布局**，不是 LrC 的“模块”布局。上游文档写明“没有 Classic 模块切换器（by design）”，所以界面不一样不是设置问题。本仓库的补丁把顶部右侧做成了 **图库｜修改照片｜打印｜导出** 四个模块，见 README。

仍然和 LrC 不一样的地方（补丁没有改动）：

| 方面 | LrC | LightCraft |
|---|---|---|
| 修改照片的面板 | 基本、色调曲线、HSL、细节、镜头校正、变换、效果、校准 | 按云端版分为 亮度 Light / 颜色 Color / 效果 Effects / 细节 Detail / 光学 Optics / 校准；纹理、清晰度、去朦胧在“效果”里；变换在裁剪面板里 |
| 右侧面板 | 可以同时看直方图、基本、历史、快照 | 右侧工具面板一次只显示一种：编辑、裁剪、蒙版、版本（快照）、历史、关键字、信息 |
| 导航器 | 左上角的面板 | 放大后在照片右下角显示的小地图 |
| Tab / Shift+Tab / T / F5 | 隐藏面板和工具栏 | 未绑定 |
| 面板排序 | 可自定义修改照片面板 | 段落顺序固定，只能折叠或单独显示（Solo） |
| 中文用词 | 曝光度、自然饱和度、减少杂色、修改照片、收藏夹 | 曝光、鲜艳度、降噪、编辑、相册。另外，参数曲线里 Highlights 和 Lights 都译成“高光”，是翻译 bug |

## 二、“左右对比没法显示修改前和修改后”：原因和用法

> **本补丁已修复第 1、2、3 条**：在网格或比较视图里按 Y 会直接进入“修改照片”的左右对比；修改前渲染出来之前，那一侧显示灰色和“正在渲染修改前…”，不再用修改后的画面顶替；分屏模式加了“修改前 / 修改后”标签；“复制修改前设置到修改后”保留当前裁剪。下面是这些问题的原因，未打补丁的官方版仍然存在。

修改前/修改后功能是有的：Y 左右、⌥Y（Alt+Y）上下、⇧Y（Shift+Y）分屏、⌥⇧Y 上下分屏、\ 只看修改前。看不到效果通常有下面几个原因：

1. **只在放大视图（Detail）里显示。** 在网格里按 Y 只会改一个状态，画面不变；之后进入放大视图时，才会突然变成左右布局。
2. **比较视图（⇧C）里的 Y 按钮没有作用。** 比较视图底栏也有“修改前/修改后（Y）”按钮，点了会亮起，但比较视图根本不读这个状态。这是上游的 bug。另外，比较视图比较的是两张不同的照片，不是修改前后。
3. **修改前要渲染一下。** 修改前那一侧渲染完成之前，会先用已经修改过的预览顶替，所以刚按 Y 时两边看起来一样，大 RAW 文件可能要等几秒。上游 issue #2248，修复 PR #3993 尚未合并。分屏模式下，修改前渲染出来之前整张图都是修改后。
4. **“修改前”指导入时的状态。** 如果效果全部来自 设置 ▸ 导入 里的默认预设，修改前也包含它们，两边会一样。只做了裁剪、拉直或旋转的照片，两边也一样，这是有意设计：修改前也套用当前的裁剪。
5. **\ 是开关，不是按住才生效。** 按一下就一直停在“修改前”，再按一次才回来。停在修改前时拖滑块，看起来像没反应。

**正确用法**：选中照片 → 按 D 或点“修改照片”进入放大视图 → 按 Y。如果两边一样，等右下角“渲染中…”结束。要把某个历史步骤设为“修改前”：窗口 ▸ 历史记录，在该步上右键 ▸ Copy History Step Settings to Before。自定义的“修改前”重启后会失效。

## 三、“保存之后没法直接用 Photoshop / PhotoCraft 打开”

> **本补丁已实现**：导出对话框新增“导出后”：无操作 / 在 Finder 中显示 / 在 PhotoCraft 中打开 / 在其他应用程序中打开…，会随“使用上次设置导出”和导出预设保存（以上游 PR #3649 为基础）。下面第 1 步“把 Photoshop 设为外部编辑器”仍然需要，导出后打开会默认用它。

**现状**
- **有“在应用程序中编辑”（Edit In）**：
  - 照片 ▸ Edit In ▸ Edit in PhotoCraft（默认 ⇧⌘E）：在原图旁边生成 `<文件名>-Edit.psd`（16 位），和原图堆叠，并用 PhotoCraft 打开。在 PhotoCraft 里 ⌘S 保存后，切回 LightCraft 会自动刷新。
  - Edit in Other Editor（默认 ⌥⌘E）：交给你指定的程序，比如 Photoshop。
- **导出对话框没有 LrC 的“后期处理 ▸ 导出后：在 Photoshop 中打开”**。上游 PR #3649 实现过这个功能，但没有合并就关闭了。
- **快捷键和 LrC 正好错开**：LightCraft 的 ⌘E 是“使用上次设置导出”，⇧⌘E 是 Edit in PhotoCraft；LrC 的 ⌘E 是“在 Photoshop 中编辑”，⇧⌘E 是“导出”。

**现在就能做的设置（不需要写代码）**
1. **把 Photoshop 设为外部编辑器**：设置（⌘,）▸ 常规 ▸ External Editing ▸ Other editor。
   - macOS 填应用名，例如 `Adobe Photoshop 2026`；Windows 填 `C:\Program Files\Adobe\Adobe Photoshop 2026\Photoshop.exe`。
   - 格式选 TIFF 或 PSD、16 位，色彩空间选 ProPhoto 或 Adobe RGB，与 Photoshop 的工作空间一致。
   - 如果用 PSD 往返，在 Photoshop 首选项里把“最大兼容 PSD 和 PSB 文件”设为“总是”。
2. **改回 LrC 的按键**：在键盘快捷键里依次设置：
   - Export…（dialog.export）设为 ⇧⌘E（会自动从 Edit in PhotoCraft 上拿走）；
   - Edit in Other Editor（photo.editInExternal）设为 ⌘E；
   - Edit in PhotoCraft 设为 ⌥⌘E。
3. 之后按 ⌘E 就和 LrC 一样：渲染 16 位 TIFF/PSD，在 Photoshop 里继续处理，保存后自动回到图库。
4. 如果一定要“导出到桌面文件夹再打开”：先导出（Export to 选 Specific folder，指向桌面上的文件夹，存成预设），再把文件拖进 Photoshop 或 PhotoCraft。以后用 ⌥⇧⌘E“使用上次设置导出”。
5. **已知 bug**（#3617/#3974）：如果某张照片的 -Edit 副本从来没保存过或已删除，再次 Edit In 会失败。避开方法：在编辑器里至少保存一次副本，删除副本后清空“最近删除”。

**后续可以做成补丁**：在导出对话框加“导出后：在 PhotoCraft / Photoshop / 其他程序中打开 · 在访达中显示”，以上游 PR #3649 为基础，约 1–2 天。

## 四、快捷键：改成 LrC 习惯

> **本补丁已实现一键切换**：帮助 ▸ 键盘快捷键 ▸ 快捷键方案 ▸ Lightroom Classic（以上游 PR #2338 为基础）。下表的改法全部包含在内，另外 ⌘N / ⇧⌘N 按“是否在修改照片”区分含义，⌘E 在外部编辑器（Photoshop）中编辑、⇧⌘E 导出。完整对照表见 [classic-keymap.md](classic-keymap.md)。下表保留作为说明。

- 和 LrC 相同的键：P/X/U、0–5、6–9、Y、\、Z、空格、W、J、V、N、F、F6–F8、⌘[ ⌘]、⌘'、⌘G、⇧⌘I、⌥⇧⌘E、⇧⌘R、⇧⌘C、⌥⌘V、⌘K 等。
- 主要的不同和建议的改法：

| LrC | LrC 功能 | LightCraft 默认 | 建议改成 |
|---|---|---|---|
| E | 放大视图 | E = 编辑面板，D = 放大视图 | view.detail → E，panel.edit → D |
| C | 比较视图 | C = 裁剪，⇧C = 比较 | view.compare → C |
| R | 裁剪 | R = 径向渐变 | panel.crop → R，tool.radial → ⇧M |
| Q | 移除 | H | panel.remove → Q |
| K | 画笔 | B | tool.brush → K |
| M / ⇧W | 线性渐变 / 蒙版面板 | L / M | tool.linear → M，panel.masking → ⇧W |
| L | 关灯 | ⇧L | view.lightsOut → L |
| ⇧⌘S | 同步设置 | 新建版本 | develop.sync → ⇧⌘S |
| ⌘U | 自动 | — | develop.auto → ⌘U |

- 本补丁另外加了模块键：⌥⌘1 图库、⌥⌘2 修改照片、⌥⌘6 打印（Windows 上 ⌘ 对应 Ctrl）。
- 上游有一个尚未合并的 PR #2338，实现了一键切换“Lightroom Classic 键位”。合并以后就不用逐条改了。
- 绑不上的 LrC 行为：
  - 需要参数的命令（自动白平衡 ⇧⌘U、目标调整工具）；
  - 按模块区分含义的键（⌘N 在图库是新建收藏夹，在修改照片是新建快照）；
  - Tab / T / F5；
  - Caps Lock 自动前进；
  - 滑块之间用 . / , 切换，用 +/- 调整。

## 五、从导入到导出：迁移和日常流程

- **迁移 LrC 目录**：文件 ▸ 导入 Lightroom 目录…，可以直接读 `.lrcat` 或 LrC 备份 zip。
  - 能带过来：文件夹、收藏夹和收藏夹集、星级、旗标、色标、层级关键字、元数据、虚拟副本，以及换算过的修改设置。
  - 带不过来：堆叠、快照、历史、快捷收藏夹、发布服务；智能收藏夹会变成普通相册。
  - 渲染效果只是近似；迁移是单向的，LightCraft 不写回 LrC 的设置。
  - 迁移前：在 LrC 里把快捷收藏夹存成普通收藏夹；重要的快照各建一个虚拟副本。
- **LrC 预设**：文件 ▸ 导入配置文件与预设…，选 LrC 的 `CameraRaw/Settings` 文件夹（.xmp）或旧版 .lrtemplate。
- **导入**：
  - 有：添加、拷贝、移动、拷贝为 DNG；按日期整理；重命名模板；导入时套用预设、元数据和关键字；自动导入。
  - 缺：“在以下位置创建副本”（第二份备份）、导入预设、联机拍摄。
- **选片**：P/X/U 旗标、0–5 星级、6–9 色标、智能相册、B 快捷收藏夹、筛选栏、自动前进，都有。
- **修改**：
  - 有：同步和自动同步、版本（相当于快照）、历史、虚拟副本、参考视图、软打样、蒙版（含 AI 对象蒙版，需要自行下载 SAM 3 模型，约 3.4 GB）。
  - 缺：渲染与 LrC 完全一致，以及相机配置文件的保真度，上游仍在改进。
- **导出**：预设、命名、尺寸、输出锐化、元数据、水印都有；缺“导出后打开”、发布服务、导出为目录。
- **打印**：本补丁的打印模块（见 README）支持长边尺寸、纵向/横向和色彩管理，**只能输出 PDF**。

## 六、PhotoCraft 能否替代 Photoshop

- **往返**：Edit in PhotoCraft 生成的 16 位 PSD 可以在 PhotoCraft 里加图层，⌘S 原地保存；LightCraft 会读取 PSD 的合并图像并自动刷新。
  - 用 PSD，不要用 TIFF：TIFF 加了图层以后，⌘S 会变成“存储为”。
  - PhotoCraft 首选项 ▸ 文件处理 ▸“最大兼容 PSD”保持“总是”。
- **快捷键**：PhotoCraft 默认就是 Photoshop 键位，支持导入 Photoshop 的 `.kys` 键位文件。首次启动时如果检测到本机装有 Photoshop，会提示导入。
- **颜色**：编辑 ▸ 颜色设置，工作空间选与 LightCraft 一致的 ProPhoto 或 Adobe RGB。
- **打印**：有 Photoshop 式的打印对话框：
  - 打印机、纸张、方向、位置和缩放；
  - “PhotoCraft 管理颜色”加打印机 ICC 配置文件、渲染方式、黑场补偿；
  - 软打样（⌘Y）和色域警告。
  - 限制：只有 Windows 能打开驱动程序自己的“打印设置”；macOS 和 Linux 走 CUPS，选不了纸张类型和打印质量；打印数据固定为 8 位。
- **Windows 注意**：PhotoCraft 默认按“仅为我”安装，LightCraft 可能找不到它。需要在 LightCraft 设置 ▸ 常规 ▸ External Editing ▸ PhotoCraft 一栏手动填路径，例如 `%LOCALAPPDATA%\Programs\ArtCraft\PhotoCraft\photocraft.exe`。
- PhotoCraft 自己的 README 写明它仍处于早期 alpha，还不能完全替代日常专业工作。

## 七、减淡、加深、海绵、快速选择、对象选择、仿制图章 / 蒙版

> **本补丁已实现下文“可以加进修改照片的快捷工具”**：蒙版面板顶部的“快速修饰”一行，含减淡、加深、海绵、快速选择、对象选择、仿制图章（⌥ 单击设源点、“对齐”选项）、快速蒙版；快捷键 ⇧B / ⇧W / ⇧Q / Q。“需要改引擎的部分”和可选的“Photoshop 修饰键位”没有做。

LrC 本身也没有这些 Photoshop“工具”。它用“画笔蒙版 + 局部滑块”和“移除工具”实现同样的效果，LightCraft 的底层能力和 LrC 基本对齐。

| PS 工具 | LrC 里的做法 | LightCraft 今天的做法 | 缺什么 |
|---|---|---|---|
| 减淡 Dodge | 画笔（K）+ 效果预设“减淡（变亮）”/ 曝光度 + | 蒙版（M）▸ 画笔（B）▸ 局部“曝光”调正值 | 没有一键入口和内置预设；同一蒙版里多笔不叠加；涂抹时看不到实时提亮；没有 PS 的“范围”（阴影/中间调/高光）和“保护色调” |
| 加深 Burn | 画笔 + 效果预设“加深（变暗）” | 同上，曝光调负值 | 同上 |
| 海绵 Sponge | 画笔 + 局部饱和度 | 画笔 + 局部“饱和度”（-100 到 +100） | 没有局部“自然饱和度”（PS 的 Vibrance 选项） |
| 快速选择 Quick Selection | 画笔的自动蒙版，或“选择对象”的画笔模式 | 画笔勾选“自动蒙版”，或颜色范围、明度范围 | 没有“拖着自动扩展到物体边缘”的区域生长 |
| 对象选择 Object Selection | 选择对象（LrC 12）：画笔或框选 | 蒙版 ▸ 对象：单击包含，⌥ 单击排除；或“描述”文字选择 | 需要自行下载 SAM 3 模型（约 3.4 GB）；只能点选，不能框选；Windows/Linux 上用 CPU，较慢 |
| 仿制图章 Clone Stamp | 移除工具（Q）▸ 仿制 | 移除面板（H）▸ 仿制 / 修复 / 内容识别 | 不能 ⌥ 单击指定源点（自动选择后再拖）；没有“对齐”选项 |
| 快速蒙版 / 图层蒙版 | 蒙版面板，O 显示叠加 | 蒙版面板，O 显示叠加，⇧O 换颜色 | 没有像素选区和图层（无损蒙版只能驱动局部滑块） |

**可以加进“修改照片”的快捷工具**（只改界面层、复用现有命令，不动引擎），约 6–8 人日：

- 蒙版面板顶部加一行“快速修饰”：
  - **减淡 / 加深**：一键新建画笔蒙版，曝光 ±1 EV；可选“范围”，用明度范围相交实现；
  - **海绵**：饱和度 ±；
  - **快速选择**：大画笔加自动蒙版；
  - **对象选择**：直接进入 AI 对象选择；
  - **仿制图章**：直接进入移除面板的仿制模式，补上 ⌥ 单击设源点和“对齐”；
  - **快速蒙版**：红色 50% 叠加加画笔。
- 默认快捷键选不冲突的 ⇧B / ⇧W / ⇧Q / Q；另提供一个可选的“Photoshop 修饰键位”（O / W / S）。
- 需要改引擎的部分单独计算，都不是必需的：局部自然饱和度、同一蒙版内多笔叠加（PS 喷枪效果）、涂抹时实时预览、真正的区域生长式快速选择、对象框选或套索。

真正的 Photoshop 式像素工具（减淡、加深、海绵、快速选择、对象选择、仿制图章、快速蒙版），PhotoCraft 都有。复杂的局部精修可以用 Edit in PhotoCraft 往返完成。

## 八、后续补丁建议（按对你工作流的价值排序）

2. 快速修饰的引擎部分：局部自然饱和度、同一蒙版内多笔叠加、涂抹时实时预览、区域生长式快速选择、对象框选。
3. 打印直接送打印机（目前只能输出 PDF）。
