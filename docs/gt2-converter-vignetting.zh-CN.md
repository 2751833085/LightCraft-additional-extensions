# GR IIIx + GT-2 强制 60mm：附加镜暗角校正

## 为什么会有额外暗角

- GT-2 是 1.5 倍增距镜，GR IIIx 的 40mm（等效）装上后变成 60mm。
- 相机“附加镜”设置打开时，会把画面裁到 75mm，正是为了把增距镜造成的四角暗角裁掉。
- 强制用不裁切的 60mm 时，整幅画面都保留，四角的暗角也一起露出来。
- 这部分暗角来自增距镜，相机不会记录。LightCraft 的“启用镜头校正”只认识裸镜头；手动“暗角”滑块最多补 1.5 档、形状固定，跟不上增距镜在四角急剧变暗的曲线。

本补丁新增 **修改照片 ▸ 镜头校正 ▸ 附加镜暗角**：用你自己拍的一张平场照测量这支增距镜的暗角，存成配置，之后对任何照片一键校正。

## 第一步：拍平场照（每种光圈拍一次就够）

1. **装上 GT-2，用你平时强制的 60mm 不裁切模式拍**，和正式拍摄一样。
2. **光圈用你最常用的**：增距镜的暗角会随光圈变化。常用全开和收小两种，就各拍一张（例如 f/2.8 和 f/5.6），做成两个配置。
3. **对着亮度均匀的东西拍**，任选其一：
   - 白平衡滤镜 ExpoDisc（77mm）整个盖在 GT-2 前面，对着阴天天空或白墙；
   - LED 灯箱（例如 Kaiser Slimlite Plano 5000K）：GT-2 贴近发光面，四角都要在发光区里；
   - 白色柔光纸（LEE 216）叠两三层罩在镜头前，对着阴天天空。
   - 不要用印刷的测试卡或白纸：光线很难打均匀，不均匀会被当成暗角“校正”进配置里。
4. **手动对焦到最近**，让纹理全部虚掉。
5. **RAW（DNG）、低 ISO。** 曝光让中心亮但不过曝，大约 +1 EV。中心过曝或太暗，软件会拒绝测量并说明原因。

## 第二步：在 LightCraft 里生成配置

1. 导入平场照，选中它，进入“修改照片”。
2. 在“镜头校正”里决定是否勾“启用镜头校正”，**以后拍照用不用它，这里就保持一致**。附加镜暗角测的是“镜头校正之后还剩下的暗角”，这样裸镜头那部分不会被重复校正。
3. 点“附加镜暗角”下拉框 ▸ “从所选平场照片创建…”。
4. 测量在后台进行，几秒钟。对话框会显示：
   - 四角最多提亮多少档；
   - 如果四角有一部分完全没有光（增距镜的成像圈没覆盖到），会提示“超出对角线 X % 的角落被附加镜遮挡”。这部分任何软件都救不回来，用裁剪工具裁掉即可。
5. 名称默认是“GR IIIx + GT-2 · f/2.8”这样的格式，可以改，然后保存。

在同一个对话框里（下拉框 ▸ “管理配置文件…”）可以重命名或删除配置。

## 第三步：应用到照片

- **单张**：在“附加镜暗角”下拉框里选配置。这次更改只算一步撤销。“数量”滑块默认 100，可在 0–200 之间调强弱。
- **一批**：先在一张上设好，再用“同步设置”或“复制 / 粘贴编辑设置”，勾选“镜头校正”。
- **导入时自动校正**（适合整次都用 GT-2 的外拍）：
  1. 在一张照片上设好附加镜暗角；
  2. 新建预设，勾选“镜头校正”（也可以同时带上你常用的其他调整）；
  3. 外拍前到 设置 ▸ 导入，把“RAW 默认值”设为这个预设，拍完导入就会自动校正；
  4. 回到裸镜头拍摄时，记得把“RAW 默认值”改回原来的设置。
  - 相机在强制 60mm 时不会记录接了 GT-2，所以没法按元数据自动识别，只能靠预设。

## 说明和限制

- 校正是非破坏性的，原始文件不变，随时可以选“无”取消。
- 测量模型：以画面中心为圆心的径向增益曲线（5 个系数），最大提亮 4 档。镜头的光轴中心和画面中心基本一致，所以裁剪、旋转后的照片同样适用。
- 增距镜的暗角会随光圈和对焦距离略有变化，常用的光圈各做一个配置最准确。
- 存了附加镜暗角的照片，用官方版 LightCraft 打开时这项校正会被忽略（其他调整不受影响）。
